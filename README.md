# ai-qa-lab

QAエンジニアが **テスト自動化** と **AI活用** を学ぶための学習記録です。

テスト計画・テスト設計・テスト実施の経験を土台に、「テストを自動化するコード」を書けるようになること、そして AI（Claude Code）を開発・QA業務に活用できるようになることを目指しています。

## 目的

- 手動テストで培った設計力（同値分割・境界値分析など）を、自動テストのコードに落とし込めるようになる
- Python・pytest・Playwright を段階的に習得し、CI（自動実行の仕組み）まで一通り経験する
- AI を「答えを出す道具」ではなく「学習とレビューの相棒」として使う方法を身につける

## 学習計画

| ステップ | 内容 | 状況 |
|---|---|---|
| 1. Python | 関数・条件分岐など、テストを書くための基礎文法 | 学習中 |
| 2. pytest | テストフレームワークの基本（assert、例外のテスト） | 学習中 |
| 3. Playwright | ブラウザを自動操作する E2E テスト | 未着手 |
| 4. GitHub Actions | プッシュ時にテストを自動実行する CI の構築 | 未着手 |
| 5. Claude Code の活用 | AI によるコードレビュー・テスト設計の補助 | 一部実践中 |

※ 5 は、学習全体を通して Claude Code にコードレビューを依頼する形で取り入れています。

## 現在の内容

`tests/` に、テスト設計技法を pytest で実装したものがあります。

| ファイル | 内容 |
|---|---|
| `tests/test_sample.py` | 年齢から料金区分（子ども／大人／シニア）を返す関数の**境界値テスト**。区分の切り替わり（12歳と13歳、64歳と65歳）を確認 |
| `tests/test_practice.py` | 購入金額から送料を返す関数の**同値分割＋境界値分析**。有効3クラス・無効1クラス（マイナス金額は `ValueError`）の境目（-1／0／4,999／5,000／9,999／10,000）を確認 |

### テスト設計の考え方（送料計算の例）

| 同値クラス | 範囲 | 期待結果 |
|---|---|---|
| 無効 | 0円未満 | `ValueError` |
| 有効① | 0〜4,999円 | 送料 500円 |
| 有効② | 5,000〜9,999円 | 送料 300円 |
| 有効③ | 10,000円以上 | 送料 0円 |

各クラスの「境目の前後」を選ぶことで、少ないテスト数で不具合が出やすい箇所（`<` と `<=` の書き間違いなど）を検出できます。

## 実行方法（Windows / PowerShell）

前提：Python 3 がインストールされていること。

```powershell
# 1. 仮想環境（プロジェクト専用のPython環境）を作成
python -m venv .venv

# 2. 仮想環境を有効化
#    ※ スクリプト実行が禁止されているとエラーになる場合は、下の補足を参照
.\.venv\Scripts\Activate.ps1

# 3. pytest をインストール
pip install pytest

# 4. すべてのテストを実行
pytest

# 詳細表示（テスト名を1件ずつ表示）
pytest -v

# 1ファイルだけ実行
pytest tests/test_practice.py -v
```

**補足：有効化でエラーが出る場合**
PowerShell の実行ポリシーで止められることがあります。その場合は、現在のウィンドウ内だけ許可して再度実行してください。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```
